# Clícalo

> **Lo que quieras hacer, clícalo.** · *Whatever you want to do, clícalo.*

Panel flotante para Windows, pensado primero para la accesibilidad: ejecuta atajos de teclado, macros, textos y acciones de mouse **solo con la pantalla táctil o la voz**.

> Estado: **M0 · cimientos** (en construcción). Ver [el plano de arquitectura](docs/architecture/blueprint.md).
